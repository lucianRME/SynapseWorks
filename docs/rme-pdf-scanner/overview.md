# RME: PDF & Document Scanner

RME: PDF & Document Scanner is a privacy-first Android document scanner with offline OCR, searchable PDFs, local processing, and user-controlled export.

> PageHarbor is now RME: PDF & Document Scanner. The product and its privacy-first principles remain the same; only the public name has changed.

## Purpose

Explain what RME PDF Scanner does, its current availability, and its privacy-first operating model.

## Who it is for

- Android users installing RME PDF Scanner
- Android users evaluating local document-scanning workflows
- Security, privacy, and compliance reviewers

## Prerequisites

- Android 8 (API 26) or later
- RME PDF Scanner installed from Google Play, or a developer build from the open-source repository
- Non-sensitive sample documents for testing

## Current availability

RME: PDF & Document Scanner is publicly available on [Google Play](https://play.google.com/store/apps/details?id=org.synapseworks.pageharbor). Current version: **1.2.0**.

## Product page

Website: [RME PDF Scanner](https://synapseworks.org/rme-pdf-scanner/)

## Capability summary

- Scan up to 20 pages in one scanner session with Google ML Kit Document Scanner
- Import page images from the gallery
- Create a normal PDF or export individual JPEG pages
- Share a PDF using the Android Sharesheet
- Run bundled, offline Latin-script OCR and select recognized text
- Copy recognized text only through the explicit **Copy Text** action
- Generate searchable PDFs locally
- Suggest safe, category-based filenames for searchable-PDF saves
- Choose export destinations through Android's Storage Access Framework (SAF)

RME PDF Scanner requires no account and has no ads, app-operated analytics or tracking, proprietary document-processing backend, or persistent document library. Its [open-source code](https://github.com/lucianRME/rme-pdf-scanner) is available under the Apache License 2.0. Google ML Kit has separate technical diagnostic disclosures; see [Privacy and support](privacy-and-support.md).

## Common issues

- A scanner session is limited to 20 pages; start another session for additional pages.
- Use non-sensitive documents during testing and do not rely on RME PDF Scanner as a document archive.
