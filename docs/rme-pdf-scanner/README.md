# RME PDF Scanner

RME: PDF & Document Scanner is a privacy-first, local-first Android document scanner with a private document library, multilingual on-device OCR, searchable PDFs, safer-sharing tools, portable backup, and user-controlled export. These pages cover version **1.7.1**, including the major **1.7.0** feature release.
